# Sync Vault

Windows 11 x64와 Apple Silicon Mac 사이에서 클립보드와 파일을 공유하는 개인 LAN 앱입니다. 각 컴퓨터에 따로 설치하고 업데이트합니다.

[릴리즈 절차](docs/release.md) · [E2E 검증](docs/e2e.md) · [원격 작업 필수 정리](docs/e2e.md#원격-작업-필수-정리) · [성능 측정과 20분 상주 기준](docs/performance.md)

## 설치 파일

Windows 11 x64는 `SyncVault-0.2.2-win-x64.exe`, Apple Silicon Mac은 `SyncVault-0.2.2-mac-arm64.dmg`를 설치합니다. 0.1.1 사용자는 새 설치본으로 한 번 교체하면 이후 버전부터 앱에서 업데이트할 수 있습니다. [v0.2.2 설치 파일](https://github.com/poyal/sync-vault/releases/tag/v0.2.2)

원격 Mac에서는 `~/Workspace/personal/` 아래에서만 작업합니다. 결과를 로컬로 회수하고 원격에는 해당 경로 안의 Git 체크아웃만 보관합니다.

## 홈에서 기기 열기

Windows와 Mac 각각에 정식판을 설치하고 같은 LAN에서 **홈 → 기기 연결**을 엽니다. 주변 기기를 선택하거나 상대의 IP와 포트를 입력하세요. 두 화면의 코드가 같으면 양쪽에서 **코드가 같아요**를 누릅니다. 등록 요청은 5분 뒤 만료됩니다.

- **클립보드** — 홈에서 내 기기를 열어 기록 공유를 켭니다. 보관 수는 원본 기기별 1~50건이며 기본값은 10건입니다. 텍스트·기본 서식·PNG를 원본 기기에 암호화해 보관합니다. 상대 기기 화면의 **내 클립보드에 복사**를 누르면 선택한 항목을 붙여넣을 수 있습니다. 파일 복사와 OS가 민감하다고 표시한 항목은 기록에서 제외합니다.
- **공유 폴더** — 내 기기 → 공유 폴더 → **폴더 위치 열기**에서 Finder나 탐색기로 자료를 넣습니다. 정식판의 기본 경로는 사용자 홈 아래 `Sync Vault/공유`입니다. 등록된 상대는 폴더를 탐색하고 **가져오기**를 누를 수 있습니다. 받은 자료는 설정에 표시된 별도 수신 폴더에 저장하며, 중복 이름에는 번호가 붙습니다.
- **상주와 잠금** — 창을 닫으면 트레이나 메뉴 막대에서 공유를 계속합니다. 화면을 잠그면 양쪽 공유 탭의 접근을 중지합니다. 파일은 잠금 해제와 재연결 후 이어받고, 붙여넣을 항목은 다시 선택합니다. 전송 상태와 저장 위치는 **가져오기 내역**에서 확인합니다.
- **기존 설치본** — 등록 기기와 기존 수신 폴더를 보존합니다. 구버전 기기는 홈에서 업데이트 안내를 표시합니다. 개발판은 독립된 프로필과 설치본을 쓰며 개발 설치본으로만 갱신합니다.

## 앱 업데이트

정식판의 **설정 → 앱 정보 · 업데이트**에서 설치 버전, GitHub 최신 정식 버전과 마지막 확인 시각을 볼 수 있습니다. **지금 확인**으로 수동 조회하거나 **새 버전 자동 확인**을 켜세요. 자동 확인은 앱을 시작할 때와 선택한 간격(1~24시간)마다 실행됩니다. 새 프로필의 기본 간격은 1시간이고, 0.2.1에서 올리면 기존 설정과 하루 간격을 이어받습니다.

새 버전이 있으면 **변경 내역 보기**를 열 수 있습니다. **다운로드**로 이 기기용 서명된 ZIP을 받은 뒤 **전송 완료 후 설치** 또는 **지금 재시작**을 선택하세요. Windows에서는 앱 교체 중 다른 작업을 했다면 작업 표시줄에서 다시 열린 창을 알려줍니다. **설치 파일 다운로드**가 표시되면 앱을 완전히 종료하고 받은 Windows EXE를 실행하거나 Mac DMG의 앱을 응용 프로그램 폴더에 대치하세요. 기존 0.1.1에서는 새 정식 설치본으로 한 번 직접 교체합니다.

## 개발·패키징

Node.js, npm, Windows의 Visual Studio C++ Build Tools 또는 Mac의 Xcode Command Line Tools가 필요합니다.

```sh
npm ci
npm test
npm run build
npm start
```

Windows에서 `npm run dist:win`, Apple Silicon Mac에서 `npm run dist:mac`을 실행합니다. 각 OS의 설치본과 업데이트 ZIP은 `release/`에 생성됩니다. 제품 식별자 및 릴리스 검증 공개키를 유지해야 기존 설치본이 새 릴리스를 신뢰합니다.

개발판 임시 전달, 정식 설치본 검증, GitHub 릴리즈 자산 서명 및 수동 게시 순서는 [릴리즈 절차](docs/release.md)를 따릅니다.

## 검증

`npm run check`는 타입, IPC 목록과 단위·통신 회귀 테스트를 실행합니다. `npm run test:e2e`는 별도 프로필 두 개로 연결 확인, 선택한 클립보드 복사, 폴더 가져오기, 오류 복구와 창 복원을 검사합니다. `npm run test:e2e:desktop -- --large`는 11 GiB 이상의 여유 공간에서 5 GiB 전송을 중단·재개합니다. `--soak`은 창을 숨긴 앱 두 개를 5초마다 20분 동안 측정합니다.

실기기 시험은 Windows에서 `SYNC_VAULT_QA_EXE`에 개발판 실행 파일을 지정하고 `SYNC_VAULT_MAC_HOST`, `SYNC_VAULT_MAC_DIR`, `SYNC_VAULT_MAC_NODE`, `SYNC_VAULT_MAC_EXE`에 같은 LAN의 SSH 별칭과 Mac의 시험 작업 폴더·Node·앱 실행 파일을 지정한 뒤 `npm run test:e2e:desktop`을 실행합니다. 양쪽의 Node 의존성이 필요합니다. `SYNC_VAULT_QA_REPORT`를 지정하면 그 경로에 스크린샷과 측정값이 저장됩니다.
