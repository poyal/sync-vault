## Mac 종료 알림 조사와 후속 검증

Mac에 남은 19시 03분·19시 05분 충돌 보고서의 실행 파일은 임시 `Sync Vault.app/Contents/MacOS/applet`이었습니다. 두 보고서 모두 번들의 실행 경로를 찾는 `CFBundleCopyExecutableURL` 호출 중 `EXC_BAD_ACCESS`를 기록했습니다. 당시 롤백 시험은 LaunchServices에 복원 앱 실행을 요청한 직후 번들을 삭제할 수 있었습니다. 시험 앱을 창 없는 네이티브 실행 파일로 교체하고, 해당 실행 파일이 지정된 프로필에 PID를 남기고 종료된 후에만 정리하도록 수정했습니다. M4에서 같은 롤백을 연속 5회 통과했습니다. 이후 사용자가 본 알림의 정확한 시각과 실행 파일을 일대일로 연결할 자료는 없었습니다.

창 없는 AppKit 편집기에 클립보드 내용을 실제로 붙여넣는 시험을 추가하면서 HTML 붙여넣기에서 한글과 이모지가 깨지는 현상을 재현했습니다. Mac 헬퍼가 UTF-8 인코딩을 명시하도록 수정했습니다. 최종 DMG에서 추출한 헬퍼로 일반 텍스트, HTML, 글꼴 굵기, 한글·이모지, PNG 및 파일 10개를 검사했습니다. 이때 생성된 `nsattributedstringagent`의 아이콘 캐시 진단에는 `isSimulated=1`이 기록됐습니다.

중간 설치본의 반복 파일 복사에서는 TLS 연결 설정이 한 번 실패해 송신 작업이 오류 상태에 남았습니다. TLS가 연결되기 전에 발생한 해당 프로토콜 오류에 한해 같은 피어로 한 번 재시도하도록 수정했습니다. 두 시도에 같은 인증서와 TLS 버전, 전체 제한 시간을 적용합니다. Windows·Mac에서 회귀 검사 9개가 통과했습니다. 새 검사는 일시 오류 복구 후 POST 한 건만 도착하는 경우, 연속 오류, 인증서 오류, 연결 완료 후 오류를 포함합니다.

임시 서명이 바뀐 Dev 앱의 일반 LaunchServices 기동에서는 새 프로필에 기기 ID를 기록하기 전 로그인 키체인 조회에서 대기하는 경우도 관찰했습니다. 시험 프로세스가 `SecItemCopyMatching`에서 응답을 기다리는 것을 확인한 뒤 종료했습니다. 최종 빌드는 키 저장소 초기화 전에 트레이의 대기 상태와 종료 메뉴를 설치합니다. 응답이 지연되는 조건에서 Windows·Mac 모두 창 없이 메뉴를 표시하고 종료했습니다. 최종 DMG의 설치·삭제·재설치, 숨김 기동 및 설정·기기 ID 보존은 모의 키체인으로 통과했습니다. 이 Mac의 코드 서명 신원은 0개였고, DMG는 임시 서명이었습니다. 실제 로그인 키체인을 이용한 최종 빌드의 무인 재설치·재기동은 미확인입니다.
