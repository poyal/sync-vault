홈과 기기

홈에서 상대 기기의 이름을 누르면 그 기기의 클립보드와 공유 폴더를 열 수 있습니다.

처음 연결

두 화면의 확인 코드를 비교하고 각각 한 번씩 확인합니다. 한쪽만 확인한 시점에는 등록 목록이 비어 있음을 검사했습니다.

클립보드 가져오기

원본 기기에 최근 복사 항목을 모아 두고, 받는 사람이 고른 항목만 내 클립보드에 씁니다.

공유 폴더 가져오기

Finder나 탐색기에서 내 전용 공유 폴더에 자료를 넣으면, 등록된 상대가 원하는 파일 또는 폴더를 선택해 저장할 수 있습니다.

오류와 잠금

저장 위치가 사라지면 내역에서 오류 원인을 확인할 수 있습니다. 원본 기기를 잠그면 열어 둔 공유 화면의 내용도 사라집니다.

검증과 측정

  • Windows와 Mac에서 단위·통신 회귀 13개씩을 통과했습니다. Windows에서는 창을 30회 닫고 열고, 렌더러를 복구한 뒤 종료 시 포트가 반환되는 것도 확인했습니다.
  • Windows EXE와 Mac DMG의 설치 파일 해시를 검증했습니다. 두 패키지의 소스 지문은 일치했고 Mac 앱 서명과 디스크 이미지 체크섬도 통과했습니다.
  • 이전 0.2.0-dev에서는 실제 Mac에서 Windows로 5 GiB를 가져오다가 2.5 GiB에서 원본 앱을 재시작했고 최종 SHA-256이 일치했습니다.

별도 앱 프로필과 OS 시험용 클립보드를 사용했습니다. Mac 시험은 모의 키체인을 썼습니다. 잠금 검증은 두 실기기에서 앱에 OS 잠금 이벤트를 전달해 진행했습니다. 전용 QA 계정의 실제 잠금·해제와 로그아웃·재로그인은 미확인입니다.
